## Antes de publicar
1. Sustituye `assets/img/plano.jpg` por tu plano definitivo.
2. Sustituye `assets/img/hero-poster.jpg` por una imagen fija de portada.
3. Sustituye `assets/video/hero.mp4` por un vídeo MP4 corto, sin sonido y comprimido.
4. Mantén exactamente esos nombres o actualiza las rutas en `index.html`.

## Publicar en GitHub Pages
1. Crea un repositorio, por ejemplo `casting-the-runes`.
2. Sube todo el contenido de esta carpeta a la raíz del repositorio.
3. Ve a Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: /(root).
7. Guarda y espera a que GitHub publique la URL.

La web está diseñada como microsite de presentación del concepto, no como una página de reservas.
